# MobAtlas 0.6.4 — Beta

The map now keeps working during combat: markers update, loot cards open, and you can pin sources or navigate from item and quest lists.

If WoW blocks the addon from opening a protected map window, press **M** and try again. A protected zone change may need to be made manually. The current selection is preserved when an action is unavailable.

Download **MobAtlas-0.6.4.zip**, put **MobAtlas** in `Interface/AddOns/`, then type **/reload**.

## На русском

Убрали общий запрет на работу карты в бою. Метки обновляются, карточки открываются, источники можно закреплять, а из атласа и списка заданий — переходить к точкам.

Если WoW блокирует открытие защищённого окна, открой карту клавишей **M**. В некоторых случаях нужную зону придётся выбрать вручную. При отказе выбранный источник сохраняется.

После обновления достаточно **/reload**. База предметов сохранена.
