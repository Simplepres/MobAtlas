# MobAtlas 0.6.5 / Следопыт

Offline loot atlas for World of Warcraft: Forever (Interface 16001).

Install this MobAtlas folder inside your Forever client’s Interface/AddOns/ folder and restart WoW. Open with /mobatlas; dungeon preparation: /mobatlas prep; settings: /mobatlas settings. Right-click the minimap book for tracking controls.

Русский: помести папку MobAtlas в Interface/AddOns/ клиента Forever и перезапусти игру. /mobatlas — атлас, /mobatlas prep — задания перед подземельем, /mobatlas settings — настройки.

Download, documentation and bug reports: https://github.com/Simplepres/MobAtlas

Early test build. Data is incomplete and is not a live creature radar. Classic reference percentages are not measured Forever rates. Unknown chances and coordinates remain unknown. Personal observations stay in local MobAtlasDB SavedVariables; the addon does not upload them. No separate Questie installation is required.

Source details and third-party licensing notices: SOURCES.md and Licenses/. A GitHub copy does not remove upstream license conditions. Item metadata from AHledger (ahledger.com). Independent community project, not endorsed by Blizzard or upstream data projects.

Language: follows WoW (ruRU = Russian, otherwise English). Use Auto / RU / EN at the top of the atlas to switch instantly; choice is saved. Item names and native item tooltips follow the game client.

Язык: автоматически по клиенту (ruRU — русский, иначе английский). Кнопка Auto / RU / EN в атласе меняет язык сразу и сохраняет выбор.
